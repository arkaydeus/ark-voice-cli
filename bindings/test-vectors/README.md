# Shared protocol vectors

`protocol.json` holds fixed byte vectors for the wire protocol in
[`PROTOCOL.md`](../../PROTOCOL.md). The Swift, TypeScript and Python clients
all test against it, so they cannot drift apart on the wire. It covers:

- `requests`: request messages and the exact payload and frame bytes a client must send. The first
  is the "A frame, byte by byte" example from PROTOCOL.md.
- `events` and `pcmFrames`: server frames and what they decode to.
- `invalidHeaders` and `validHeaders`: headers a reader must reject (with the reason) or accept,
  including the 64 MiB payload limit.
- `samples`: `s16le` and `f32le` sample conversion, matching the server's arithmetic.

Request payloads are canonical: compact JSON, keys sorted, absent fields omitted, non-ASCII as raw
UTF-8 and `/` unescaped. The server accepts any valid JSON. Clients write the canonical form so the
same request is the same bytes in every language. Hex strings are lowercase.

The vectors are hand-checked data, not generated by any client. When the protocol changes, update
them alongside PROTOCOL.md.

`wav.json` holds shared WAV parser fixtures: canonical extensible PCM and float
GUIDs, altered GUID tails, truncated extensible headers, and a data chunk before
its format chunk. All three bindings validate these independently of WAV writers.
